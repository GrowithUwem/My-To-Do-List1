# AI To-Do List

A simple to-do list with an AI feature: type a big task and click "Break it down"
to get 3-6 smaller subtasks generated by Claude, which you can add to your list
with one click.

## How it works

- `index.html`, `style.css`, `script.js` — the frontend. Tasks are saved in the
  browser's localStorage.
- `api/breakdown.js` — a serverless function that calls the Gemini API to
  break a task into subtasks. This keeps your API key on the server, not
  exposed in the browser.

## Deploy it (takes about 10 minutes)

1. Get a free Gemini API key at https://aistudio.google.com/apikey (sign in
   with a Google account, click "Create API key"). No card required. Copy it.
2. Push this folder to a new GitHub repository.
3. Go to https://vercel.com, sign in with GitHub, click "Add New Project",
   and import the repository. Leave all build settings as default (Vercel
   auto-detects this as a static site with an API folder).
4. Before deploying (or after, in Project Settings > Environment Variables),
   add:
   - Key: `GEMINI_API_KEY`
   - Value: (the key you copied in step 1)
5. Click Deploy. Vercel gives you a live URL like
   `https://your-project-name.vercel.app` — that's your live to-do list.

Note: on Google's free tier, prompts and outputs can be used to improve their
models. Fine for a school project with no sensitive data, just worth knowing.

## Running locally (optional)

You need the Vercel CLI to run the serverless function locally:

```
npm install -g vercel
vercel dev
```

Then open the local URL it gives you. Without the CLI, opening `index.html`
directly in a browser will still show the to-do list, but the AI button won't
work since there's no server to call.
